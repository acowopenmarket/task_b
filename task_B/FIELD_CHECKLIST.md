# taskB现场检查（RGB-D全图模式）

当前识别范围就是相机整幅画面。使用RGB-D一致性定位及原坐标转换，不识别箱子，不划区域，不指定颜色，不拍空箱。

- [ ] 同一个选定物体完整进入相机画面；object_mask 对应目标，depth_object 与 rgb_object 区域基本吻合。
- [ ] 真实标定安装未变，机械臂反馈与图像同步；核对夹爪原偏移、行程、网络和串口。
- [ ] 从用户设置的观察/释放位开始；有效源区域完整可见；返回路径有净空；下方安排接收区域。
- [ ] 先只读--capture，只有PRESENT且localizable/top_valid均true才有抓取目标。
- [ ] 当前--execute显式运行时重新采集；默认姿态、44毫米修正、补偿后法兰Z下限均核对。
- [ ] 到位才闭合一次，电机反馈完成才竖直抬升，抬升完成后才横向返回。
- [ ] 返回后静止新拍；ABSENT松爪结束，PRESENT松爪并新定位，UNKNOWN只采集或超时。
- [ ] 故障停止后续发送，不自动重发，不把软件退出当急停。

四角和中心各运行一次，只是人工验收位置，不输入位置编号。记录每次运行目录、RGB-D定位理由、候选XYZ、顶部质量、两层修正、运动反馈、开合、复查和重试。

彩色/深度不一致、目标深度缺失不能当成ABSENT。当前没有完整碰撞规划；成功复查表示原目标位置已清空，不证明传感器验证持物或全程未滑落。
