# 当前实现

- rgbd_candidate.py：全画面深度分层/连通区域、孔洞轮廓填充、彩色 GrabCut、一致性评分及区域有效深度中位数。不拟合桌面，不检测箱子，不要求红色。
- vision.py：调用新定位模块，使用原 add_base_coordinates/手眼标定转换坐标，估计目标顶部，基于上次目标位置的局部深度验证移除。
- core.py：抓取与复查状态机、44毫米插入规则、夹爪法兰补偿和 Z 下限；已删除全画面障碍高度估计阻断。
- hardware.py：原实时同步采集、真实反馈和夹爪驱动保持。没有发送新的硬件指令。

深度分层采用重叠窗口，以区域近邻的深度差区分凸出目标和背景，不依赖全局桌面平面。彩色分割以深度提案的外接窗口初始化，不是独立目标语义识别。多候选时优先区域重合与支持面积较好的候选，不再因多个区域一律拒绝。目标贴近图像边缘不再一律拒绝，但完整可抓取形状仍需现场验证。

中心取融合掩膜外接框中心；相机 Z 为掩膜内有效深度中位数。三维点是表面候选点，不是体积中心。目标内部无效深度不插值成实测点。初次无目标返回 UNKNOWN；抓取后仅在原目标区域有足够测量且深度变远时确认 ABSENT，画面整体改变或原目标深度缺失不能算移除成功。

限制：当前是几何与外观一致性定位，不理解目标身份；其他凸出物也可能入选。目标需与近邻存在可测深度差和外观差异，大幅倾斜/曲面/极薄/透明物体、多物体叠放尚未验证。固定夹爪姿态、原硬件协议和工作区规则保持。
